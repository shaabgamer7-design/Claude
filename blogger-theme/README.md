# Ghulam Hussain Farms: Blogger theme v2 (exact copy of the approved design)

`ghulam-hussain-farms-theme.xml` is the theme. `pages/` holds the five static page bodies.

## Install (about 10 minutes)

1. **Blogger > Theme > ▼ next to Customize > Backup.** Download your current theme.
2. **▼ again > Edit HTML.** Click in the editor, Ctrl+A, Delete.
3. Paste the whole `ghulam-hussain-farms-theme.xml`, then click **Save** (floppy-disk icon).
   If Blogger offers to remove old widgets, accept.
4. **Pages > New page** (repeat 5 times). In each page, switch the editor to **HTML view** (pencil menu), paste the
   matching file from `pages/` (the grey comment at the top of each file lists Title, Permalink and Search description).
   Right panel settings:
   - **Permalink > Custom permalink:** `mango-varieties`, `mango-price`, `our-orchard`, `wholesale-export`, `contact`
   - **Search description:** paste from the comment, then **Publish**.
   - Do not turn comments on.
5. **Settings > Mobile / Reading:** nothing to change. The theme is responsive, so phones get the same design.
6. **Settings > Crawlers and indexing:** keep "Enable custom robots.txt" off; turn "Enable custom robots header tags" on only if you
   want to set them yourself (the theme already adds noindex to search, archive and 404 pages).
7. **Google Search Console:** add `https://ghulamhussainfarms.blogspot.com/`, open **Sitemaps**, submit `sitemap.xml`
   and `sitemap-pages.xml`.

The homepage journal shows your latest 3 posts and stays hidden until you publish a post.
